# Car Speed Analyzer 🚗

A simple Python mini project that reads car data from a file and analyzes it using Object-Oriented Programming (OOP).

## Features
- Read cars from a text file
- Display all cars
- Count moving cars
- Find fastest and slowest car
- Calculate total and average speed
- Display stopped cars
